# Analizator-jako-ci-energii-elektrycznej-oparty-na-FPGA
Projekt przedstawia system monitorowania jakości energii elektrycznej w sieciach trójfazowych z wykorzystaniem układów FPGA oraz środowiska LabVIEW. Aplikacja umożliwia pomiar napięć i prądów, analizę parametrów jakości energii oraz wykrywanie zakłóceń w czasie rzeczywistym.
